# Photos for Osteria Lume

The page has six photo spots. Generate each image with an AI image tool (ChatGPT, Gemini or similar), save it as a **.jpg with the exact file name shown**, and put it in the `img/` folder. Each photo appears automatically in the right place on both versions of the page.

**Tips**
- Generate one image per chat message, and paste the **style line** at the end of every prompt so all six photos look like they came from the same shoot.
- If a result has visible text, logos, warped forks or extra fingers, ask the tool to regenerate.
- Keep each file under about 400 KB so the page loads fast. If the tool gives you a large PNG, convert it at squoosh.app (JPG, quality 75, about 1600 px wide).

**Style line (add to every prompt):**
> Photorealistic editorial restaurant photography, shot on a full-frame camera with a 50mm lens, shallow depth of field, warm candlelit ambient light with soft shadows, rustic Italian osteria, dark walnut wood and linen textures, natural colors, no text, no logos, no watermark.
